# 路线图：从模拟到树莓派巢穴

## 目标形态

```
                ┌──────────── 树莓派（巢穴，24 小时开机）────────────┐
                │  C1 本体：基因组、化学状态、行为网络、记忆、能量账本   │
                │  世界规则层（保守序列）：回收堆、消化核验、批准闸门    │
                │  实时 tick 循环（5 分钟）+ 状态持久化到固态          │
                │  GPIO 传感器：温湿度、光照、有人在不在               │
                └───────────────┬───────────────────────────────┘
                     局域网（HTTP/WebSocket 或 MQTT）
          ┌─────────────────┼─────────────────┐
     笔记本客户端        台式机客户端          手机（只能住在 app/小组件里）
     沙盒文件夹扫描      沙盒文件夹扫描
     用户是否在用        用户是否在用
     充电状态            渲染身体
```

- 本体只有一份，在树莓派上。设备上的客户端只负责感知环境和画出身体。
- 模拟里的"云端巢穴"就是树莓派。所有设备都关机时，C1 回到这里，代谢继续运行。
- 演化和大规模实验放在电脑上跑，树莓派只负责让 C1 活着。

## 阶段

| 阶段 | 内容 | 前提 |
|---|---|---|
| 0 | 在模拟里继续优化（HANDOFF 清单第 1–5 项） | 无 |
| 1 | 巢穴服务上树莓派：tick 循环、持久化、本地接口 | 存档与恢复 |
| 2 | 第一块真实栖息地：一台电脑的一个沙盒文件夹，真实消化模块 | 阶段 1 |
| 3 | 更多栖息地；手机受系统限制，只能住在 app 或小组件里 | 阶段 2 |
| 4 | 真实的"手"：Claude API，token 成本换算成能量，批准界面 | 阶段 2 |
| 5 | 现实世界感官（追加感官基因）和执行器（智能插座，经批准） | 基因组版本兼容 |
| 6 | 用真实记录校准模拟器，重新演化 | 阶段 2 运行一两周 |

## 为什么巢穴用树莓派而不用电脑

C1 的身体几乎不需要算力（30 天模拟在虚拟机里不到 2 秒），关键在功耗、能不能接传感器、是否独立于栖息地。

| | 树莓派 5 | N100/N150 迷你主机 | 现有台式机 |
|---|---|---|---|
| 待机功耗 | 约 2–4 瓦 | 约 6–7 瓦 | 15 瓦到几十瓦 |
| 接传感器 | 自带 GPIO | 要 USB 转接或单片机 | 同左 |
| 当巢穴 | 合适 | 合适 | 它本身是栖息地，关机巢就没了 |

2026 年内存涨价后，树莓派配齐配件已经和入门迷你主机差不多贵，选它是为了省电和 GPIO，而不是为了便宜。备选方案：迷你主机 + ESP32 接传感器。

## 硬件清单（2026 年 11 月的建议）

价格以下单时当地授权代理为准。据 2026 年 9 月的报道，官方美元价约为：4GB 110、8GB 175、16GB 305。

**必买**

- 树莓派 5 **4GB**（C1 只用几百 MB；"手"在云端，不需要 8GB/16GB；预算紧时 2GB 也够）
- 官方 27W USB-C 电源（5V 5A）。手机快充头多数在 5V 下只给 3A，USB 口会被限流
- 官方主动散热器
- 官方 SSD 套件（**标准版** M.2 HAT+ 加 256GB 2230 固态）。标准版附带 GPIO 加高排针，能和主动散热器叠装；紧凑版没有加高排针
- 外壳：官方外壳装 M.2 HAT+ 要拆掉盖子和风扇，要么先不装壳，要么买兼容 M.2 HAT+、留 GPIO 开口的第三方外壳
- 32GB 存储卡（装系统和救急用，平时从固态启动）
- 网线

**建议买**

- 官方 RTC 电池（断电断网时时间不乱；C1 有昼夜节律）

**阶段 5 再买**

- 面包板、杜邦线
- BME280（温湿度，I2C）、BH1750（光照，I2C）
- 人体存在：HC-SR501 红外（便宜，但人不动就测不到）或 LD2410 毫米波（静坐也能测到）
- 可选的小屏幕：C1 回巢时在实物上也能看到它
- 执行器先用联网的智能插座，不要直接接 220V 继电器
